# Doctor Clinic Appointment Booking System

- A lightweight web-based solution to digitize appointment handling for small clinics and rural healthcare centers.

## Problem
In small towns like gondal, clinic operations are mostly manual, leading to:

- Long waiting time for patients
- Repeated explanation of medical history
- Poor appointment tracking
- Difficulty in managing patient records

## Solution
A digital system where:

- Patients can book appointments online
- Doctors can manage appointments and patient records efficiently

## Objectives
- Reduce patient waiting time
- Provide structured scheduling
- Maintain patient medical history
- Improve doctor efficiency
- Simple and user-friendly interface

## Features
### Doctor Module
- Register & Login
- View patients
- Access medical history
- Manage appointments

### Patient Module
- Register & Login
- View doctor availability
- Book appointment (date & time)
- Add symptoms/description
- Download appointment details

## Appointment Management
- Time-slot based booking
- Prevents double booking
- Stores appointment records

## Data Management
- Patient details
- Doctor details
- Appointment records
- Medical history

## Tech Stack
- HTML5
- CSS3
- JavaScript
- PHP
-  MySQL

## Non-Functional Requirements
- Fast system response
- Secure authentication & data protection
- Easy to use interface
- Reliable performance
- Scalable for growing users

## Stakeholders
- Doctors
- Patients

## Assumptions
- Users have internet access
- Doctors manage their schedules
- Patients provide correct information

## Summary
This system simplifies clinic operations by providing an organized, digital platform for appointment booking and patient record management — improving efficiency for doctors and convenience for patients.
